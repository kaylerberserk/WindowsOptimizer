# WindowsOptimizer

Windows 11 optimizer with three product files: `All in One.cmd` (one portable batch, strict ASCII/CRLF), `launcher.ps1` (download/elevation), and the French user README. `Tools/`, `Game Configs/`, LICENSE and Git metadata are resources. Agent instructions are English; human documentation and console messages are French. Keep authored explanatory comments out of code; put necessary constraints and sources here. Preserve licenses, upstream notices, shebangs and tool directives.

Before producing or citing measurements, gains, durations, VM or gaming-PC results, read `~/projects/winopt-bench/AGENTS.md`. It excludes all connections to `pc-gaming` until explicitly requested, requires one VM operator, and distinguishes VM mechanics from gaming gains.

## Verification

Before choosing validation, citing or producing metrics, or deciding batch/launcher structure changes, read [docs/verification.md](docs/verification.md). It owns the conditional contract checks, measurement methods and execution traps. There is no repository test suite; the external HP lab check is partial static proof, not PowerShell, launcher or Windows execution proof.

`44` means non-ASCII/NUL, `42` invalid line endings, `43` unreadable file. The format command exists twice: in the batch (using `%WINOPT_SELF%` and suppressed output) and in [docs/verification.md](docs/verification.md#contract-checks). Update both in the same commit. Published LF returning `42` is expected: `.gitattributes` stores LF in Git and checks out CRLF; raw GitHub serves LF. The batch validates before its first GOTO/CALL, normalizes a temporary copy, relaunches and propagates its exit code. The launcher also explicitly normalizes CRLF. Preserve both paths; `44` is rejected without repair. Do not change attributes to force CRLF blobs, add UTF-8/chcp 65001, accents or typographic quotes to the batch.

## Project and publication contract

- Keep code, README and publication aligned. Measure README figures from code or HTTP, never estimates (methods in [docs/verification.md](docs/verification.md#measurement-methods)).
- Preserve the deliberately single, dense, portable batch. Navigate by label, not line number; avoid extra layers/files.
- Windows 11 is the only supported validation target. Legacy Windows 10 paths promise no compatibility. VM coverage excludes laptops, real GPU/network hardware, effective Defender disablement, MAS and WinUtil.
- Restore captured state or a documented Windows fallback. Deleting a value is not always the inverse operation. Tell the author before changing a value or profile axis, even if internal logic suggests another choice.
- Research Windows tweaks with recent web evidence: understand the mechanism, compare Microsoft documentation with technical forums, reproducible tests and field reports. Microsoft documentation can be incomplete, outdated or overly cautious. Keep sources here, outside code and the user README.
- `main` publishes raw files directly to users and the launcher. Public paths are contracts: `launcher.ps1`, `All in One.cmd`, `Tools/Timer & Interrupt/SetTimerResolution.exe`, `Tools/NVIDIA Inspector/nvidiaProfileInspector.exe`, and its `Kaylers_profile.nip`. Rename/move only with a coordinated batch/launcher/README release and `curl -sI` checks on old/new URLs. Already distributed batches use `WINOPT_RELEASE_BASE_URL`; raw GitHub does not redirect.
- `Game Configs/`, LICENSE and `.gitignore` can move without raw-URL effects. No batch/launcher caller was found for Fortnite templates, `Tools/O&O ShutUp10/ooshutup10_kayler.cfg`, `GoInterruptPolicy.exe` or `MeasureSleep.exe`; do not assume they are dead without author agreement. Executed Valorant settings live in `::VALPS`, not the separate template: changing only one causes drift.
- Bundled Tools binaries lack documented source/version/license provenance; do not invent it.

## Technical constraints

These are maintenance constraints transferred from authored code explanations; historical observations below are not new measurements.

- Startup/launcher: prefetch the timer before elevation because proxies/user sessions may be unavailable under RunAs; retain the batch fallback. The launcher destination must keep the batch lookup path relative to `WINOPT_SOURCE_DIR`: `Tools/Timer & Interrupt/SetTimerResolution.exe`. Pass the same publication base to optional resources and launch a dedicated elevated CMD window. Establish a valid local working directory after elevation. The worker inherits initialized parent context. Integrity-token SIDs `S-1-16-12288`/`16384` avoid the Server-service dependency of `net session`. Try child `prompt $E` before PowerShell for ESC; it leaves the caller's PROMPT unchanged. Missing ANSI uses empty colors. Hardware text uses the console code page, not UTF-8; replace typographic apostrophes unrepresentable in OEM. Read ProcessorNameString before WMI; NVIDIA detection excludes virtual GPUs/machines.
- Profiles: `INIT_PROFILS` owns normalization/composite flags. Usage owns input/I/O/GPU latency; power owns energy/NIC/plan. Gaming+MaxPerf alone gets aggressive Nagle/DelACK and RSC/LSO. The Defender workload profile follows the PERFORMANCE MAX power profile (`PROFIL_POWER=0`): Tout optimiser applies it without confirmation because the usage question is already asked; Windows-default mode restores captured values, or documented defaults when no capture exists. Default laptops to Eco, desktops to MaxPerf; retain actual detected laptop type. Timer diagnostic BCD overrides are removed for every profile. Silently select the target power plan before sections 1–6 write SCHEME_CURRENT; section 7 still executes in sequence. Finish runtime downloads before restarting network adapters.
- Helpers: class enumeration filters numeric NNNN subkeys, excluding Configuration/Properties. Match the adapter `InterfaceGuid` to `NetCfgInstanceId` to locate its device class key; do not infer that key from adapter order. Assignment consumes caret escaping before `for /f`. `STEP_ERRORS` aggregates helper failures; `STEP_RESULT` consumes/resets it and must not report unconditional success. Read ERRORLEVEL before `set` resets it. Keep goto routing where inline if/else assignment is ambiguous. Missing services may be ignored; verify existing services after writing.
- Interaction: O/N/M maps to 1/2/3; failed `choice.exe` (255, closed input) must never apply settings or loop forever. Visible menus reset interactive state. Allow reading errors before runtime screens clear the console. Indicators distinguish verified `[OK]`, processed `[FAIT]`, section end `[TERMINE]`, skipped `[IGNORE]`, warnings and errors; green processing does not prove state.
- Safe settings: documented scope/storage does not prove runtime policy support. Persist the entire first baseline before any mutation; never overwrite prior entries. Security capture/import uses the process's default registry view, matching native reg.exe. Validate saved BCD tokens before registry import; native read failures are not absence, and baseline renewal must be explicit.
- System: keep InitialKeyboardIndicators, PeriodInNanoSeconds, F1/COM, Store access, Bluetooth/Hello/RDP/Spooler/PlugPlay intact. ShowFrequent affects recent-file display, not indexing. Keep DiagLog and SEMgrSvc Manual on Normal+Eco laptops (battery E3/SRUM and modern power settings depend on them). Preserve one-time hosts backups. Win32PrioritySeparation stock was 2, Gaming 0x26; MsMpEngCP.exe writes were denied even elevated. MMCSS stock observed Medium/Normal/Priority 2/GPU Priority 8.
- Browser policies: DoH accepts off/automatic/secure; `allow` is ignored. Automatic permits plaintext fallback on filtered networks. NetworkPredictionOptions=2 disables prediction; NewTabPagePrerenderEnabled affects only new tabs. Thread Director Attributes controls visibility, not scheduling (2 visible, stock 1); Eco hides it. SCHEDPOLICY affects hybrid CPUs only; do not confuse Core Parking GUIDs ending 583 (E/class 0) and 584 (P/class 1), or Energy Saver `de830923...` with PCIe ASPM `ee12f906...` in its PCI Express subgroup.
- Memory/storage: reuse validated HW_RAM before querying again; compression depends on the 8 GiB threshold in SET_MEMORY_POWER_PROFILE. Stock Prefetcher was 3, SfTracingState 1 (Windows rewrites it at boot); absence is not stock for the latter. NTFS observed LastAccess=-2147483646, 8.3=2, others 0; stock long paths disabled. Keep Windows TRIM scheduling. Native nvmedisk.sys support is documented for Server 2025; do not revive undocumented client FeatureManagement/Storport overrides.
- NVIDIA: MaxFrameLatency belongs to each device class key, not GraphicsDrivers. Use Windows\Temp when elevated user TEMP might be unmapped; environment-based PowerShell copies preserve exclamation marks. NPI CLI import requires >=3.0.1.10. Restore only imported Base Profile SettingIDs through ResetValue (DRS_RestoreProfileDefaultSetting + SaveSettings), preserving unrelated customizations.
- TCP: minRto belongs to `set supplemental`, not `set global`. Obsolete window-scaling heuristic wsh differs from supported forcews. initialRTO concerns SYN establishment, not established connections: Gaming 3000/2 follows documented values; Normal 1000/4 follows observed 25H2 client state, not a universal default. Stock congestion provider observed cubic. LanmanServer Size=1 is the client default; removing FastSendDatagramThreshold restores the native 1024-byte fast-path threshold. Nagle apply/restore must cover all interface keys, including disconnected ones, symmetrically; absent keys restore native behavior.
- Input: Normal+Eco laptops retain Windows pointer behavior; other historical profiles keep 1:1 motion. Observed stock: acceleration 1/6/10, KeyboardDataQueueSize=100, MouseDataQueueSize absent, absolute-pointer values 0, StickyKeys=510, ToggleKeys=62, FilterKeys and HID overrides absent. These observations are not portable defaults.
- Energy: preserve OEM/custom plans, global hibernation/fast-start preferences and driver-owned WDF values. PowerRestoreDefaultPowerSchemes deletes all plans. Ultimate Performance `e9a42b02` was hidden/nonactivatable on 25H2 until duplicated to a fixed GUID; keep reuse idempotent. USB changes target the selected plan with one final activation. Keep hardcoded SUB_PROCESSOR where localized aliases fail. Optional GPU driver keys may be absent without error. Stock VetoPolicy=0, Attributes=1 for Thread Director/P/E parking and 2 for PCIe visibility were observed, not universally inferred.
- Timers/storage calls: do not activate the disabled 80-byte TimerCoalescing override: boot crash 0x1E/Recovery 0xC0000001 was attributed to the Windows initialization path, with no reliable registry workaround. Let Windows manage it. MaxPerf Dynamic Tick tuning is experimental/hardware dependent; Eco removes it and restores legacy-disabled HPET. Create timer destination before transfer; hidden Start-Process kept SetTimerResolution alive where batch `start` did not. Never pipe a batch helper to PowerShell Out-Null: cmd treats it as an unknown program and may terminate the remaining script. New-ItemProperty -Name takes one string in PS5.1; loop over names in the shared storage traversal covering IoLatencyCap too.
- Security: internal Force PerfMax wins; Gaming keeps VBS/HVCI, Normal restores snapshot or the observed 25H2 fallback. Converge every managed option across previous profiles. Microsoft “Configure added LSA protection” maps RunAsPPL=1 to UEFI lock, 2 to protection without lock (new Windows 11 22H2+ default). Registry/policy cannot remove an existing UEFI variable; recovery needs Microsoft's LsaPplConfig.efi. Keep RunAsPPL=2; captured RunAsPPLBoot may be 2, fallback leaves it absent. Restore only CFG/SEHOP choices without resetting unrelated mitigations; HVCI may keep the vulnerable-driver blocklist active. Defender reactivation must mirror direct Start=4 writes even when SCM rejects a loaded-driver change; report effective state on both paths. The hosts block makes Defender flag the file (`SettingsModifier:Win32/PossibleHostsFileHijack`); Microsoft documents a Defender exclusion for a deliberately modified hosts file. Add it only when the write succeeded (`HOSTS_RC=0`), for the hosts file alone, never the `etc` folder or a parent; exit code 10 means already excluded, nothing to do.
- AI: use official Notepad DisableAIFeaturesInNotepad policy; legacy Copilot policy does not block the modern app. Anchor registry readback patterns so 0x1 does not match 0x10/0x18. Preserve native stderr and do not blame an unproved component. Recall AllowRecallEnablement=0 and DisableAIDataAnalysis=1 delete saved snapshots: every invoking screen must disclose deletion. Optional DISM component removal/reboot status must not invalidate successful primary policy application. Do not broaden changes to voice, typing or general permissions.
- Removal: `timeout` fails with redirected stdin; use the existing ping delay. `rd` needs `for /d` enumeration for wildcards. Any OneDrive User Shell Folders reference protects the whole folder: KFM may place Desktop/Documents/Pictures there, including cloud-only files. Uninstaller exit codes do not prove deletion. Stop Explorer before deleting locked icon caches and restart it. Edge system/provisioned package state must be verified; Edge Update policies are mainly guaranteed on domain-joined devices. Remove provisioned apps before installed packages, use exact package identities, and decide success from final state rather than intermediate errors (legacy Win10 column/package behavior is not a support promise).
- Cleaning: preserve Diagnosis/WER roots and ACLs, Windows Update DataStore/ReportingEvents.log, active System/Application/Security event logs, recovery `$SysReset`/`$Windows.~BT`/`$Windows.~WS`, ESD/user recovery data, performance caches and Recall snapshots. Old Windows installation deletion requires confirmation. Do not stop cryptsvc unnecessarily; `net stop /y` avoids hidden dependency prompts. cleanmgr /sagerun covers all disks and ignores /d; select an unused StateFlags id in 0..65535, never overwrite a user's profile or force a fixed fallback. Skip if no free candidate. Keep worker logs outside the shared console and strip ANSI from text logs.
- Backup/restore: retain the five newest batch copies. Capture both runas verbs before changing ownership; require complete native exports plus atomic hash-bound receipts. Preserve unverifiable legacy/partial captures and refuse writes. Verify hashes/scope before import, retain captures on refusal/readback mismatch, mark restoration before resumable cleanup and remove the receipt last. reg import may announce success on stderr; inspect its native code.
- File handling: preserve WINOPT_SELF_BACKUP_SOURCE set with delayed expansion off, including `!` in paths and exit text. Keep EnableExtensions until exit /b closes SETLOCAL. Balance pushd/popd on every path, including pushd failure. Hosts Latin-1 (28591) is byte-preserving; ASCII would corrupt bytes above 127. Ownership removal needs takeown AND icacls DACL grants; locale determines /d y or o, and `*S-1-5-32-544` resolves administrators across languages.
- Runtimes: VC14 Installed=1 can survive uninstall with Visual Studio C++ present (StackOverflow #67493523); require the main DLL too. Minimum 14.40 supports VS17.10+ std::mutex changes. Use the correct x86/x64 registry views; no x64 package on 32-bit Windows. curl >=7.66 supports parallel missing-package downloads with individual fallback; one signature validation returns reject bits 1=x86/2=x64, unusable results reject both. Keep installer logs outside cleaned download directories. DirectX detection covers all June 2010 DLLs in each architecture, not one per family; d3dcompiler_47, xaudio2_8/9, xinput1_4 belong to Windows. curl/BITS/PowerShell remain ordered download fallbacks.
- External tools: download to an admin-only named ProgramData subdirectory to prevent same-user substitution before execution. MAS/WinUtil lack Authenticode signatures; the URL allowlist is the trust boundary, and signature checking only rejects an invalid certificate. Never overstate that protection.
- Valorant: refuse writes while the game can save settings; never force termination. Preserve here-string settings, first backup, encoding detection, read-only attribute and write verification. The separate template is not an extraction source.

Numbered `REM n.n - ...` lines are catalogue metadata consumed by winopt-bench, not explanatory comments. Preserve their text and placement until producer and consumer share a replacement contract; unchanged batch execution alone does not prove catalogue/coverage compatibility.

## Execution guards

Never test the full batch on a real machine: it changes system settings. Full runs belong in `~/vms/win11/`, under the bench's authorization/operator rules. Windows 10 is out of scope; never run win11 and win10 VMs simultaneously or stop/reset another thread's VM.

Obtain explicit confirmation for published commit amendment, reset --hard, file deletion, main or remote changes unless already authorized in the current scope. Preserve unknown files as potential active work.
